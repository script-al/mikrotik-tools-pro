TECHNICAL NOTES

Storage & Session

  • User accounts are stored in localStorage (browser-only, no backend required).
  • Session persists until you click Logout or clear browser data.
  • Social login (Google / Facebook / GitHub) is simulated — demo accounts are created locally.
  • Passwords are hashed client-side using a djb2 variant before storage.
  • Profile avatars are stored as base64 data URLs.
  • To fully reset all data, clear localStorage in DevTools → Application.
